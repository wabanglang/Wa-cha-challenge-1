## Objective

Test whether a REAL implementation compiles the shortest valid path instead of executing framework stages by ceremony.

## Core acceptance

```text
DETERMINISM: same normalized input → same path/output
NO-INVENTION: no fabricated evidence/causality/authority
EXPLICIT-UNKNOWN: unsupported states remain visible
MINIMALITY: every executed optional module is necessary
TRACEABILITY: every branch links to input/rule
SAFE-BLOCK: rights/safety/authority violations block prohibited action
```
