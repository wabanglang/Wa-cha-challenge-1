# Public issue architecture

1. `[DISCUSSION] What if “broken society” is partly a social-infrastructure failure?`
2. `[MODEL] Build and falsify the causal graph`
3. `[EVIDENCE] Create an evidence ledger for every major claim`
4. `[SOLUTION] REAL — Reconnect → Enable → Anchor → Learn`
5. `[PILOT] Design a 90-day REAL neighborhood cell`
6. `[METRICS] Measure dignity, agency, stability, connection, and cost without gaming them`
7. `[GOVERNANCE] Prevent the “solution” from becoming another system of control`

Each public issue must expose contradictions, distinguish hypothesis from proof, permit counterevidence, and state falsification/failure conditions.
